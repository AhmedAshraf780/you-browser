# You — web + notes in one place

Electron (Chromium) shell where `youtube`, `cache.md`, `test.excalidraw`, `doc.pdf`
live as equal tabs next to each other.

## Run from source

```bash
npm install   # downloads Electron binary (needs access to github releases)
npm run dev   # Vite HMR + Electron
npm run build # out/main + out/preload + out/renderer
```
`edit`
If `electron --version` says "failed to install correctly" in a sandbox,
run `node node_modules/electron/install.js` once with network, then retry.

## Desktop build (Linux AppImage)

```bash
npm run dist        # release/UniBrowser-0.1.0.AppImage
npm run dist:dir    # unpacked dir for inspection
./release/UniBrowser-0.1.0.AppImage
```

Notes: AppImage only (no `dpkg-deb` on this machine); `npmRebuild` stays
off so the prebuilt pty binary survives packaging; the file allowlist in
`package.json` ships just the main-process closure (asar went 268MB →
~22MB); the renderer is fully bundled. Packaged builds serve the app over
`app://` (`src/main/protocol.ts`, real MIME/CORS/ranges) instead of
`file://`, whose module/fetch/worker quirks break the PDF viewer —
first launch after this change resets renderer-local prefs (theme, tabs)
once, vault files untouched.

## How it works

- `src/main/index.ts` — BrowserWindow with `webviewTag: true`, vault IPC.
  Vault = any folder you pick via **Open folder** in the sidebar (native dialog),
  persisted in `userData/settings.json`. Watched with chokidar — edits from
  VSCode/Obsidian/file manager refresh the sidebar live. Traversal outside the
  vault is rejected.
- `src/renderer/components/FileExplorer.tsx` — folder tree (dirs first, alpha
  sort, dotfiles hidden). Filter box, active-tab highlight, flash on
  newly created nodes. Right-click any node (or empty space) for
  New note / New drawing / New folder / Rename / Delete. Rename and delete
  retarget/close affected tabs automatically. New tabs via the `+ New tab`
  button (opens a web tab).
- Adblocking (`@ghostery/adblocker-electron` in `src/main/index.ts`) —
  uBlock-compatible filter lists (EasyList + tracking) enforced at the
  session level for all web tabs. Engine downloads once on first run, cached
  in `userData/adblock-engine.bin`. Toggle in the toolbar, persisted in
  `settings.json`. YouTube is exempted from network blocking (it stalls the
  player and trips the anti-adblock wall) and is handled instead by an
  in-page skipper (`src/renderer/adskip.ts`, injected from `WebTab.tsx`):
  pre-rolls seek to end + mute, skip buttons auto-click, ad chrome hidden.
- Tab strip uses real Lucide pictograms per type (theme-colored); web tabs
  show the site's actual favicon with globe fallback, and the vault panel
  docks live terminal sessions below the explorer (jump to any session,
  `+` for a fresh vault-rooted shell, `×` kills).
- Terminal renders Nerd Font glyphs via bundled SymbolsNerdFontMono
  (`src/renderer/assets/fonts`), so devicons/powerline render anywhere.
- App icon generated by `scripts/make-icon.py` (stdlib-only gradient Y on
  abyss); rerun after edits, ships in `npm run dist`.
- 10 themes × dark/light: Black Metal · Immortal (true-black dark),
  Rosé Pine, Catppuccin, Gruvbox, Tokyo Night, Dracula, Nord, Everforest,
  Solarized, Ayu.
  Markdown preview and the Excalidraw canvas follow the mode. Theme choice
  persists in localStorage. Picker lives in Settings now.
- Wallpaper theme (the row at the top of the picker): derives a full theme —
  background, text and accent — from the current desktop wallpaper, and
  re-derives it whenever the wallpaper changes. Detection is KDE (Plasma
  appletsrc, including the slideshow's *current* image, so the theme follows
  each slide) with a GNOME `gsettings` fallback, plus a manual "Choose image…"
  override in Settings → WALLPAPER. Following is belt-and-braces: filesystem
  events on Plasma's config are debounced (so a read can't land mid-write and
  conclude "unchanged") *and* the config is re-read every few seconds, so a
  missed event can't leave the theme stuck on stale colours; Settings shows
  `source · live (n changes)`. The image reaches the renderer through the
  locked-down `you-wall://` scheme (it only ever serves the tracked file, so it
  cannot read arbitrary paths); the renderer samples it on a canvas and turns the
  pixels into the same 19 custom properties the hand-written themes use, so it
  participates in the normal picker/mode/override machinery. Saturation is
  deliberately damped on surfaces and text/accent colours are contrast-corrected,
  so a garish wallpaper still yields a readable app. `npm run verify:wallpaper`
  checks detection, the derivation (asserted on WCAG contrast), the live follow,
  the write-burst race and the no-event poll fallback against synthetic fixtures.
- Kanban (`KanbanTab.tsx`): the rail `Board` is the global workspace board
  (persisted `ub.kanban`); any vault `.kanban` file (root or nested) opens as
  its own full board tab with 800ms autosave. Create via explorer `New
  board` / `+ Board`, open from sidebar, omnibox, quick-open, home recents.
  Rename retargets open board tabs; corrupted files fall back to a fresh
  board instead of a blank screen.
- Vocabulary (`VocabTab.tsx`): spaced-repetition deck for English learning.
  The rail-less global deck lives in `ub.vocab`; any vault `.vocab` file (root
  or nested) opens as its own deck (700ms autosave). SM-2 scheduling with
  Again/Hard/Good/Easy grading (keys 1–4, Space reveals). Create decks via
  explorer `New deck` / `+ Deck`. Capture a word from any page selection with
  `Ctrl+Shift+E` (falls back to the omnibox text) into the default deck or any
  `.vocab` file. Any card can be starred (☆/★) as a **favourite** — `toggleFavourite`
  persists the flag in the global deck and inside `.vocab` files, the All view has a
  `★` filter, and the study card has its own star (starring auto-files the word even
  when auto-save is off). Home shows an English card with the due count.
- Word feeder (`src/main/study.ts` + `wordsource.ts` + `StudyOverlay.tsx`): the
  app sources words live — nothing is hardcoded. A timer in the main process
  asks **Datamuse** for words around the learner's *interests* (free-text seeds,
  default `programming, lifestyle, conversation`); each hit carries a
  corpus-frequency tag, and the chosen **level** (A2 → C1) selects a frequency
  window, which is how "B1" is approximated. It also enumerates **phrasal verbs**
  live via Datamuse `sp=* <particle>` (`set up`, `give up`, `care for`…) and
  splits topical hits into **lexical verbs** vs other words, then round-robins
  the three pools so the feed mixes parts of speech instead of being
  noun-dominated. Each item is resolved to a real entry — **Simple English
  Wiktionary** first (learner-register definitions), then **Free Dictionary API**,
  then Datamuse — for IPA, part of speech, meaning and an example. Entries are
  cached in `userData/word-cache.json`, so an item is fetched once and repeat
  prompts work offline. The card appears bottom-centre (phrasal verbs get a
  badge); when the window isn't focused a native notification fires instead and
  clicking it focuses You and opens the card. Shown items are auto-filed into the
  deck (toggleable) and skipped so prompts stay new. Interval, level, interests
  and auto-save live in Settings → English Words; the card's ☆ stars the item as
  a favourite; `Ctrl+Shift+E` still captures a word you meet yourself.
- Calendar (`CalendarTab.tsx`): full-page month grid where every day is a
  writable cell (day notes persisted locally), vault-activity dots, per-day
  touched files, one-click daily notes into `journal/YYYY-MM-DD.md`.
- Excalidraw is pinned to git-fresh preview build `0.18.0-43a92e6` (Oct 12)
  instead of the stale `0.18.1` release — includes the newest board: notes
  feature, pen pressure range, new keybindings. Pinned exact, not caret.
- Settings panel (`SettingsPanel.tsx`): appearance, adblock toggle, vault
  switcher, clear-history, shortcuts, about.
- Performance: heavy editors (CodeMirror+vim, xterm) are `React.lazy`
  split — initial parse is ~350KB instead of ~2.2MB; the Excalidraw engine
  prefetches on idle; markdown preview re-parses 300ms off the keystroke
  path; vault refreshes coalesce autosave storms (leading + 400ms
  trailing).
- All tabs stay mounted: switching hides instead of destroying, so media
  keeps playing and editors keep undo/scroll.
- Embedded terminal + Neovim (`src/main/pty.ts`, `TerminalTab.tsx`):
  `node-pty` (lydell prebuild, no compilation) + xterm. A terminal tab on a
  vault file opens it in your own Neovim (config, plugins, LSP); on a folder
  (or empty) it drops to a shell there. Explorer menu: Open in Neovim /
  Terminal here. Palette follows the app theme. Tabs keep running in the
  background like web tabs. Terminal zoom: `Ctrl`/`Cmd` + `+`/`-`/`0`,
  persisted per machine.
- Session restore: tabs + active tab + split layout persist to localStorage
  and come back on launch (validated, capped at 30).
- Downloads: save dialog defaulting to ~/Downloads, native notification on
  completion, for all web-tab downloads.
- Find: `Ctrl+F` opens a floating find bar (match counts, Enter/Shift+Enter,
  Esc) on web tabs via `findInPage`; in markdown notes it opens CodeMirror's
  search panel. Intercepted in main so it fires from video pages too.
- Vim mode in notes: toggle in any markdown header, persisted globally.
- Split view: `◫` beside `+` pins a second tab beside the active one, with
  swap/close in the pane header. Mounts stay alive, so both panes keep
  playing/editing. Persisted across restarts.
- Firefox PDF viewer (official Mozilla shell from the pdf.js tag matching
  `pdfjs-dist`, `PdfTab.tsx`): full toolbar, sidebar (thumbnails/outline/
  attachments/layers), find, annotations, dark UI following the app mode.
  `web/` shell + `l10n/en-US/viewer.ftl` committed; engine + cmaps + fonts
  + fluent synced from npm on install (`sync-pdfjs`) under `vendor/` (never
  `node_modules/` — the packager's excludes strip those paths from the
  asar). Two documented patches in `web/` (re-apply if re-copied from
  upstream): the build-time version check in `pdf_viewer.js` is skipped for
  raw sources, and `workerSrc` in `app_options.js` points at `../build`
  instead of the absent `../src` tree. Verified: all 69
  viewer modules resolve. Local vault PDFs offline; remote http(s) PDFs
  keep the native viewer (CORS).
- `Ctrl+T` quick-open palette (`QuickOpen.tsx`): floating fuzzy finder over
  open tabs, vault files, URLs and web search. Intercepted in the main
  process (`before-input-event` on host + guest contents), so it fires even
  when a video page has focus. `Ctrl+B` travels the same path (skipped
  inside pages so Docs bold keeps working).
- Markdown editor (`MarkdownTab.tsx`): CodeMirror 6 with md highlighting and
  a single var-driven theme covering all 5 palettes × dark/light, live
  preview via `marked`, 600ms autosave.
- Home dashboard (`HomeTab.tsx`, opened with `+`): live clock + greeting,
  recent sites (from persisted browsing history), recent notes (by file
  mtime, live from the watcher), local scratchpad (autosaved, no file),
  and a persisted to-do list. Fully themed.
- Scrollbars: thin themed overlay-style bars on every in-app surface
  (explorer, tabs content, editors, home, popups) via global
  `::-webkit-scrollbar` + `scrollbar-*` rules. Web pages keep their own —
  guest documents can't be styled from the host.
- `src/preload/index.ts` — `window.vault` bridge (contextIsolation safe).
- `src/renderer/` — React shell:
  - `tabs.ts` — `Tab = web | markdown | excalidraw | pdf`, `target` = URL or vault path
  - `store.ts` — zustand tab state, seed: youtube + cache.md + test.excalidraw
  - `components/WebTab.tsx` — `<webview partition="persist:unibrowser">`
  - `components/MarkdownTab.tsx` — textarea + `marked` preview, 600ms autosave
  - `components/ExcalidrawTab.tsx` — `@excalidraw/excalidraw`, JSON autosave every 1s
  - `components/PdfTab.tsx` — iframe (URL or vault base64 blob)
  - `App.tsx` — tab strip + omnibox (URL, search, or `cache.md` path) + vault sidebar
- `vault/` — your files. Drop `.md`, `.excalidraw`, `.pdf`, `.kanban` or `.vocab`
  here, they appear in the sidebar.
